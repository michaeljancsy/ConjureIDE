## Design

Tanh soft-clipper / saturator with a real-time oscilloscope showing the channel-1 output waveform. Drive 0–24 dB pushes the signal into tanh; Mix dry/wet blends parallel saturation; Output trims post-clip level (−24…+6 dB). The visual hook: as Drive comes up, a sine input progressively flattens into a square — the tanh curve reshaping the signal in real time on a green-on-black scope.
