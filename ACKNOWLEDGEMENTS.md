## Neural Amp Modeler

The NAM inference in `rust/conjuredsp-rs/src/nam.rs` and
`rust/conjuredsp/nam.py` is an independent reimplementation of the `.nam`
model format and reference inference defined by Steven Atkinson's
MIT-licensed [neural-amp-modeler](https://github.com/sdatkinson/neural-amp-modeler)
and [NeuralAmpModelerCore](https://github.com/sdatkinson/NeuralAmpModelerCore)
projects. The example `.nam` model files under `tone3000_py_demo/` come from
NeuralAmpModelerCore's example models (MIT).

## TONE3000

ConjureDSP can browse and download tone captures from
[TONE3000](https://www.tone3000.com). ConjureDSP is an independent project —
it is not affiliated with or endorsed by TONE3000. Tone captures downloaded
through the integration carry their capturers' own licenses.

Setup scripts download these at build time; each ships under its own license:

- [Monaco Editor](https://github.com/microsoft/monaco-editor) (MIT) — in-plugin code editor
- [xterm.js](https://github.com/xtermjs/xterm.js) (MIT) — in-plugin terminal UI
- [python-build-standalone](https://github.com/indygreg/python-build-standalone) — bundled free-threaded Python runtime (PSF and component licenses)
- The Rust toolchain (`rustc`, standard library; MIT/Apache-2.0) — bundled for WASM preset compilation
- [uv](https://github.com/astral-sh/uv) (MIT/Apache-2.0) — Python package management

The full license inventory for Swift, Rust, JS, and Python dependencies is
generated by `scripts/generate-licenses.sh` into
`ConjureDSPExtension/Resources/licenses.json` and shown in-app under
Settings → Third-Party Licenses.
